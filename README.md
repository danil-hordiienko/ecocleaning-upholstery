# EcoCleaning — Upholstery Cleaning

Standalone landing page for professional upholstery cleaning at home in Torrevieja and Costa Blanca.

**Website:** https://danil-hordiienko.github.io/ecocleaning-upholstery/

## Features

- English, Spanish, Ukrainian and Russian.
- Language selection: saved preference, browser language, then English.
- Photo quote request through WhatsApp with selectable cleaning items.
- Responsive layout, keyboard navigation and reduced-motion support.
- Local images, fonts and SVG icons; no build dependencies.

## Files and preview

`index.html`, `styles.css`, `script.js` and `translations.js` form the page. Assets and fonts are included in this repository. Serve the repository root with any static web server for a local preview.

## Publication

GitHub Pages publishes the root of the `main` branch. `.nojekyll` preserves the static files. Push changes to `main` to update the website.

This is a separate landing page. The main ecocleaning.es website is maintained separately.
